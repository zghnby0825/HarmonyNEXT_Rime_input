# VGHFly（适配超越输入法2.5.3版本）：

基于原主题修改内容：


1、中/英 键盘样式仿照“小鹤音形-胖版-app”键盘设置。
〉https://flypy.cc/help/#/sj

2、工具栏依次是-菜单-表情-剪贴版-中/英切换-软件本体。

3、新增 全选、复制、粘贴 等一系列快捷操作。

使用方法:

1、克隆项目;

2、将项目打包为.zip格式压缩包;

3、导入超越输入法中可使用小鹤音形+配套主题键盘;

4、如果需要单独导入键盘:将项目中的themes单独进行压缩打包导入即可.
